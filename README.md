# yash-rampuria.github.io

Personal portfolio of Yash Rampuria. Plain HTML, CSS and JavaScript with no build step.

## Structure

```
index.html              all page content
assets/css/style.css    styles (light and dark themes)
assets/js/main.js       nav, theme toggle, scroll reveals, hero graph animation
assets/images/          figures from the GGraph, V-LEAD and MAVBE papers
```

## Common updates

- **Resume:** save the PDF as `Yash_Rampuria_Resume.pdf` in the repo root. The Resume buttons stay hidden until this file exists.
- **Photo:** save a square headshot as `assets/images/headshot.jpg`. It appears next to the "MS Robotics" pill in the hero.
- **Content:** edit the matching section of `index.html`.

## Preview locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
